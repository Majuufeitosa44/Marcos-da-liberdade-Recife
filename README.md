# Quem dá nome às ruas — Santo Antônio e São José (Recife)

Mapa interativo da toponímia dos bairros de Santo Antônio e São José, no centro do Recife.
Par recifense do mapa de toponímia de Nantes Métropole — cooperação Recife–Nantes (ARIES / AFD-FICOL 2, GT4).

Versão de teste: **Marcos da Liberdade**.

## O que tem aqui

- `index.html` — o mapa completo, num arquivo só (dados embutidos).
- `dados_tracado_santo-antonio_sao-jose.geojson` — recorte do traçado oficial usado no mapa.
